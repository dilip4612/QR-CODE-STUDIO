
# ⚡ QR Code Studio Pro

A professional QR Code Generator built using Python and Streamlit.

## Features

- Generate QR codes for URLs and text
- Email and phone QR codes
- Wi-Fi QR code generation
- vCard contact QR codes
- SMS QR codes
- Custom QR colors
- Centre logo integration
- PNG and SVG downloads
- Bulk QR generation using CSV
- ZIP download for bulk QR codes
- Session-based QR history

## Technologies Used

- Python
- Streamlit
- QRCode
- Pillow
- CSV
- ZIP

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
